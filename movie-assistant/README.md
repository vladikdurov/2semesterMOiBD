# Movie Advisor

Рекомендательная система фильмов (задания 4.1 и 4.2).

## Возможности

1. Топ-10 популярных фильмов (взвешенный рейтинг)
2. Топ-10 фильмов по выбранному жанру
3. 10 похожих фильмов по контенту (жанры + год)
4. 10 похожих фильмов по коллаборативной фильтрации

## Данные

В папку `data/` положите:
- `movies.csv`
- `ratings.csv`

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python server/main.py
```

Откройте в браузере: **http://127.0.0.1:5000**

- Интерфейс: http://127.0.0.1:5000/
- Справка API: http://127.0.0.1:5000/api/help

## API

| Метод | Путь | Параметры | Описание |
|-------|------|-----------|----------|
| GET | /api/top | limit=10 | Топ популярных |
| GET | /api/by-genre | genre, limit=10 | По жанру |
| GET | /api/similar-content | title, limit=10 | По контенту |
| GET | /api/similar-collab | title, limit=10 | Коллаборативная фильтрация |
| GET | /api/genres | — | Список жанров |
| GET | /api/help | — | Справка |
